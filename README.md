# VoxelGame

**[Скачать лаунчер — VoxelLauncher.exe](https://github.com/GutmanUKG/voxel-game-builds/releases/latest/download/VoxelLauncher.exe)**

Запустите скачанный файл: лаунчер установится в `%LOCALAPPDATA%\VoxelGame`, создаст ярлык «VoxelGame» на
рабочем столе и в меню «Пуск», сам скачает игру и дальше будет её обновлять. Прав администратора не нужно.

- Windows 10/11, 64 бит.
- У лаунчера нет цифровой подписи: если Windows покажет «Система Windows защитила ваш компьютер», нажмите
  «Подробнее» → «Выполнить в любом случае». Это нужно только при первом запуске.
- Сохранения лежат в `%USERPROFILE%\AppData\LocalLow\DefaultCompany\VoxelGame`, обновления их не трогают.
- Удалить игру: папка `%LOCALAPPDATA%\VoxelGame` и ярлыки «VoxelGame».

Все версии и списки изменений — в [Releases](https://github.com/GutmanUKG/voxel-game-builds/releases).
